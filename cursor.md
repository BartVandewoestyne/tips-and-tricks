# Cursor

## Configuration files

* Global (user) config files:
** Main IDE settings (editor settings, keybindings, snippets, extensions, app state/storage): `~/.config/Cursor/`.
** Cursor-specific user config: `~/.cursor/`
* Project (workspace) config (usually checked into git):
** Workspace settings in `.vscode/settings.json`
** Other Cursor settings in `.cursor`
